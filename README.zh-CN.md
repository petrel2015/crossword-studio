一个**零依赖的纯 Web 应用**：输入一组英文单词——或整篇英文文章——自动生成报纸风格的填字游戏（Crossword）。在线作答、编辑线索、打印 A4 试卷（可选答案页）、用一个链接分享整套拼图。无需服务器、无需账号、无需构建。

> __💡 核心目标：粘贴词表或文章，得到一份可打印、可分享的报纸风填字游戏——一切都跑在你的浏览器里。__

---

## 输入模式

| 模式 | 你提供什么 | 线索来源 |
| --- | --- | --- |
| __词表__ | 每行一个单词，竖线后可加线索 | 你自己的线索；AI 词典式线索；或留空（后续可编辑） |
| __文章__ | 粘贴一篇英文文章 | __AI 文章式线索__（引用文中情节、模仿文章语气）或 __离线原文填空__（`选自原文："…the keeper trimmed the ______ each dusk"`） |

文章模式下，候选词**完全在本地提取**（过滤功能词、复数归并、专有名词识别、按词频与位置评分排序），由你勾选想要的词，也可以手动补充自定义词。

## 功能特性

- __经典填字生成__：在严格的交叉规则下（交叉字母一致、禁止并行重叠、禁止意外相邻串词）编织单词，按标准方式编 Across/Down 序号，多轮随机尝试中挑出最紧凑的报纸风布局
- __对失败诚实__：放不进棋盘的词会连同原因一起列出——绝不悄悄丢弃
- __完整作答界面__：点击输入（桌面键盘与手机输入法均支持）、方向键导航、方向翻转、点击线索定位并高亮当前词、检查（红笔标记）、提示、揭示字母 / 单词 / 整盘、计时器
- __进度自动保存__：字母、揭示记录与用时按拼图为单位存入 localStorage
- __编辑__：可改标题、难度和任意线索；重新生成只重排布局，保留你改过的线索
- __打印 / PDF__：A4 纵向、纯黑白；__打印专用标题可编辑__；日期可显示 / 隐藏 / 自定义；可选答案页；屏幕预览即真实版面；「导出 PDF」= 浏览器的*存储为 PDF*
- __链接分享__：整套拼图压缩进 URL 哈希（`#p=…`，gzip + base64url）——任何人打开链接即作答同一套题，无需服务器
- __英文 / 简体中文__：右上角切换，默认跟随浏览器语言
- __多端适配__：桌面双栏、平板线索双栏下排、手机单栏 + 工具栏横滑

## 快速开始

无需构建，两种运行方式：

```bash
# 方式一 —— 直接双击 index.html 用浏览器打开

# 方式二 —— 起本地服务（推荐；对 CORS 严格的 AI 服务商需要 http 环境）：
python3 -m http.server 8741
# 打开 http://localhost:8741/
```

部署 = 把文件夹拷到任意静态托管（GitHub Pages、Netlify、对象存储、内网文件共享……）。没有后端。

## 配置 AI 线索

点击右上角 **AI 设置**，填入任意 OpenAI 兼容的 `/chat/completions` 接口：

| 服务商 | Base URL |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` |
| DeepSeek | `https://api.deepseek.com/v1` |
| Ollama（本地） | `http://localhost:11434/v1` |

- API 密钥只保存在你浏览器的 localStorage，只发给你配置的接口。
- 只有无线索的词（词表模式）或文章节选 + 选定词（文章模式）会被发送，其他数据不离开浏览器。
- 没配置 AI？一切照常——线索留空可编辑，文章模式自动回落到完全离线的原文填空式。
- 若服务商禁止浏览器直连（CORS），请换用支持 CORS 的接口或保持手动写线索。

```
js/
├── generator.js      ★ 填字算法——纯逻辑、无 DOM、可在 Node 运行。
│                       错误以错误码表示（issue.* / reason.*），由 UI 翻译。
├── extract.js        ★ 文章 → 候选词 + 挖空句——纯逻辑、可在 Node 运行：
│                       分词、停用词、复数归并、专有名词识别、评分、
│                       带词边界的挖空替换。
├── i18n.js           中英字典、语言检测、data-i18n 应用器
├── codec.js          拼图 ⇄ URL 哈希（gzip + base64url，CompressionStream）
├── storage.js        localStorage：进度 / 草稿 / AI 设置
├── ai.js             可选的线索撰写——词典式或文章式
│                       （文章截断、每批 20 词、进度回调）
├── solve.js          交互棋盘：选择、输入、检查/揭示、计时
├── print.js          A4 页面构建器（屏幕预览 = 真实打印输出）
└── app.js            编排：视图、工具栏、编辑抽屉、弹窗、输入模式
test/
├── gen-test.js       算法不变量（交叉、串词、编号、确定性、压力测试）
│                     —— 5,527 项断言
├── extract-test.js   提取不变量（停用词、归并、专有名词、挖空/裁剪）
│                     —— 29 项断言
└── dom-test.js       jsdom 全应用端到端 —— 81 项断言
```

`dom-test.js` 端到端驱动两种输入模式：生成、输入、检查、提示、揭示、编辑、分享链接还原、打印标题/日期覆盖、语言切换与进度持久化。

### 架构说明

__数据流__：

```
词表 ─────┐
          ├─► Extract（本地，文章模式）─► 候选词 ─► AI / 挖空 ─► 线索
文章 ─────┘                                                  │
                                                             ▼
        Generator（N 轮随机尝试 · 放置规则 · 编号）──────► layout
                                                             │
        ├─► 作答界面（输入 / 检查 / 揭示 / 计时 ⇄ localStorage 进度）
        ├─► 打印构建器（A4 预览 = 真实打印 DOM · 标题/日期覆盖）
        └─► URL 编解码（gzip + base64url ⇄ #p=… 分享链接）
```

__关键技术点__：

- __放置引擎__：稀疏 Map 网格允许布局生长期间坐标为负；每次放置都按经典交叉规则校验，以 `交叉数×权重 − 包围盒增长 − 长宽拉伸 + 抖动` 评分，并在多轮间重试（后续放置可能解锁此前失败的词）。按 放置数 → 交叉数 → 紧凑度 → 方正度 选出最优尝试。
- __确定性中带变化__：同一种子必得同一布局；每次 Generate 换新种子，所以「重新生成」给出全新布局。
- __防篡改分享链接__：`#p=` 链接经同一校验引擎回放（`buildLayout`）；损坏或被改动的链接会明确报错，而不是渲染出坏盘。
- __进度键__：进度以「布局 + 答案」的哈希为键存储，改线索或标题不会清空作答记录，而重新生成后的新布局自然全新开始。
- __语言切换__：一次遍历重套所有 `data-i18n` 文案并重建动态视图（线索列表、棋盘无障碍标签、编辑抽屉），同时保留进度与运行中的计时器。
- __打印预览即打印输出__：同一份 A4 DOM 在弹窗内缩放展示，打印时移入 `#printRoot`——预览所见即打印所得。
- __挖空安全__：只替换整词匹配且忽略大小写（`CARE` 不会误伤 `CAREFUL`），长句围绕空格窗口化裁剪。

## 技术栈

- 纯 HTML / CSS / JavaScript（ES2017+，经典脚本——`file://` 直接打开也能用）
- 零运行时依赖；jsdom（仅开发）用于端到端测试
- 现代 Web 平台能力：`CompressionStream`、`ResizeObserver`、`navigator.share`、`localStorage`
