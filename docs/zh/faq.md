# 常见问题

关于 Crossword Studio 能做什么、不能做什么的简短问答。深入内容：
[使用指南](./usage.md) · [功能设计文档](./features/index.md) ·
[隐私说明](./privacy.md)。

**能完全离线使用吗？**
能——它是零运行时依赖的静态页面。从磁盘打开 `index.html`，生成、
作答、打印全程不需要网络。只有 AI 线索需要联网（见
[AI 线索](./usage.md#ai-线索)）。

**我的数据会发到服务器吗？**
不会。没有服务器。词表、文章、拼图、进度和 AI 设置都存在浏览器
localStorage；[隐私说明](./privacy.md)审计了全部网络行为。应用唯一
可能发出的外呼是可选的 AI 线索请求，且接口由你自己配置。

**能出其他语言（中文、德语……）的填字吗？**
网格与线索以英文为中心：单词会被清洗为 A–Z 字母（3–12 个），提取和
AI 线索也假设英文文本。*界面*是双语的（英文/简体中文），但拼图内容
应当是英文。

**为什么有些词不在拼图里？**
它们在真实填字规则下放不进去。这些词会连同原因列在棋盘下方（无公共
字母 / 所有交叉冲突 / 超出难度网格上限）——绝不悄悄丢弃。点重新生成
换个种子，常常就能放下。

**没有网站也能分享拼图吗？**
能。**分享**会复制一条 `#p=` 链接，整套拼图都在里面；对方打开即玩。
双方都不需要服务器和账号。原理见[分享链接](./features/share-links.md)。

**多人能协作一套拼图、或看到彼此进度吗？**
不能。没有账号也没有服务器；进度只存在于单个浏览器配置里。协作
需要托管点什么——这是刻意的非目标。

**有手机 App 吗 / 能当 PWA 安装吗？**
没有应用商店 App，也没有 PWA/Service Worker 安装。网站做了响应式，
移动浏览器体验良好；收藏网页即可。

**支持哪些浏览器？**
现代常青浏览器（Chrome、Edge、Firefox、Safari），桌面与移动均可。
分享链接优先用 `CompressionStream`，老引擎回落普通 base64url——只是
链接更长而已。

**必须要有 OpenAI 账号 / API 密钥吗？**
不必——AI 线索是可选功能。不配置时线索留空可编辑，文章模式用离线
挖空线索。想用的话，任意 OpenAI 兼容接口都行（OpenAI、DeepSeek、
火山方舟、本地 Ollama……），密钥只存你的浏览器。见
[AI 线索](./usage.md#ai-线索)。

**为什么「导出 PDF」打开的是打印对话框？**
因为浏览器的*存储为 PDF* 目标就是 PDF 导出。Crossword Studio 构建
精确的 A4 页面，由浏览器渲染成 PDF。应用不内置 PDF 库。

**能放到学校内网 / 我自己的网站上吗？**
能——部署就是拷贝一个静态文件夹，见[部署指南](./deployment.md)。
