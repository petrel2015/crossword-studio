# 故障排查

Crossword Studio 的真实故障模式，按排查顺序给出。这里没有覆盖的
问题 → [提 Issue](https://github.com/petrel2015/crossword-studio/issues)。

## 构建 / 生成

### 「我的词被忽略了」

直接看词表输入框下方：每个问题都带原因列出。

1. **「最少 3 个」** —— 剥离非 A–Z 字符后不足 3 个字母。
2. **重复** —— 单词出现多次；只保留第一个。
3. **空格问题** —— 条目内含空格。
4. 看输入框下方的统计（如「12 个单词 · 8 个有线索」），确认实际解析
   结果。

修复：每行一个单词，3–12 个 A–Z 字母，不要重复。

### 「文章模式点生成没反应」

1. 至少要勾选一个候选词（复选框或 **Top 10 / 全选**）。零选择时生成
   被设计性地阻止。
2. 太短的文章在提取阶段就被拒绝；请粘贴更长的文本（一段以上）。
3. 未配置 AI 却选了 **AI 文章式**，会有 toast 提示并留在构建页——把
   线索风格换成**选自原文（离线挖空）**或**自动**。

### 「棋盘下方列了一些词，棋盘里却没有」

这是如实的失败报告，不是 bug。原因含义：

| 原因 | 含义 | 怎么办 |
| --- | --- | --- |
| *与已放置的单词没有公共字母* | 不可能交叉 | 补充起连接作用的词，或删掉该词 |
| *没有合法位置——所有交叉点均与现有布局冲突* | 有交叉可能但全部冲突 | 点**重新生成**（换种子），或删换某个词 |
| *超过当前难度的 N×N 网格上限* | 单词超出该难度的网格上限 | 换难度（困难允许更大网格） |

## 作答

### 「打字没反应」

1. 先点击一个格子——需要选中格（当前词与当前格会高亮）。
2. 触屏设备应弹出输入法；没弹的话再点一下格子。
3. `file://` 场景可能与某些浏览器扩展相互干扰——试试本地伺服
   （`python3 -m http.server 8741`）。

### 「我的进度丢了」

进度按浏览器配置存在 localStorage，以拼图的「布局+答案」为键。以下
情况不保留：

- 清除站点数据 / 无痕浏览会话结束，
- **重新生成**拼图（新布局 = 全新进度），
- 从*另一个*布局的链接打开同一拼图。

编辑线索或标题从不重置进度。

### 「我不在的时候计时器还在走」

计时器统计的是从开始作答起的经过时间，不是活跃时间。想重来点
**重置**。

## 打印 / PDF

### 「打印输出和预览不一致」

应该一致——预览就是真实的打印 DOM。如果浏览器打印对话框里显示别的：

1. 确认打印对话框里缩放为 **100% / 默认页边距**。
2. 想要纯卷面效果就关掉页眉页脚（浏览器附加的 URL/日期）。
3. 打印的只有弹窗构建的 A4 页；应用界面被打印 CSS 隐藏。如果预览里
   出现界面元素，说明 `style.css` 缓存过期——强制刷新
   （Ctrl/Cmd+Shift+R）。

### 「导出 PDF」灰色或找不到

「导出 PDF」就是浏览器打印对话框里的*存储为 PDF* 目标——Chrome/Edge
里叫「另存为 PDF」。应用不内置 PDF 渲染库。

## 分享

### 「链接打开后是报错，不是拼图」

`#p=` 负载未通过校验。原因：

1. 链接被聊天/即时通讯应用截断——复制完整 URL。
2. 有人手工改过哈希——任何改动都会破坏 gzip 流。
3. 分享者复制链接后又重新生成了拼图；每个布局都是独立的链接。

请对方用**分享**重新生成一条链接。

### 「链接在我这里正常，朋友打开却是旧拼图」

你分享的是上一次生成/编辑步骤的链接。每改一次哈希就变——复制一条
新的。

## AI 线索

### 「AI request failed (HTTP 401/403/404)」

1. **401/403** —— API 密钥错误或无权限；检查密钥及其配额/授权。
2. **404** —— Base URL 不对。应用会在 Base URL 后拼
   `/chat/completions`，所以 Base URL 必须停在该路径*之前*
   （如 `https://api.openai.com/v1`）。
3. **"Could not reach the AI endpoint"** —— 网络失败或 CORS。部分
   服务商完全禁止浏览器直连；换支持 CORS 的接口，或保持手动写线索。
   这是服务商侧限制——应用（和托管）都无法绕过。

### 「AI 线索只补了一部分」

每批 20 词，某批失败不会中断其他批——部分结果会保留。再点一次生成/
AI 补写即可重试剩余，或手动补写。

## 赞赏弹窗

### 「二维码不显示」

弹窗懒加载 `vendor/qrcode.min.js`。如果二维码区域一直空着：

1. 确认 `vendor/` 目录随其他文件一起上传了。
2. 看 browser console 是否有脚本的 404。
3. 移动端点支付宝可能直接跳去了支付 App——返回后会出现二维码兜底。

## 语言 / 显示

### 「界面语言不对」

右上角切换（EN / 中文）。默认顺序：你保存的选择，然后是浏览器语言。
按钮没反应就强制刷新——新旧 `i18n.js` 与 `index.html` 混用会让字典
错位。

## 报 bug

请附上：浏览器与操作系统、复现步骤、期望结果、截图，以及（生成类
bug）确切的词表或文章。Console 报错（F12 → 控制台）几乎总是决定性的。
