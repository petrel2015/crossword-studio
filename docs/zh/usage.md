# 使用指南

Crossword Studio 能做什么，一步步讲清。项目定位见
[README](../../README.md)；功能背后的设计决策见
[功能索引](./features/index.md)。

## 运行应用

- **直接打开**：双击 `index.html`。除部分 AI 服务商外，`file://` 下全部功能可用。
- **本地伺服**（推荐）：

  ```bash
  python3 -m http.server 8741
  # 打开 http://localhost:8741/
  ```

或使用在线版：<https://petrel2015.github.io/crossword-studio/>。

界面为英文或简体中文——右上角切换，默认跟随浏览器语言，你的选择会被记住。

## 用词表生成拼图

![词表模式](../img/builder-zh.webp)

1. 停留在**词表**标签（第 1 步）。
2. 每行一个单词。可在竖线后加自己的线索：`apple | It keeps the doctor away, supposedly`。
3. 输入框下方显示解析结果（多少个单词、几条线索），解析问题会列在下面（见错误处理表）。
4. 可勾选「**用 AI 补写缺失的线索**」（仅词表模式显示；需先[配置 AI](#ai-线索)，否则线索留空、后续可编辑）。
5. 在**拼图设置**（第 2 步）：填标题（最长 72 字符）、选难度：
   - **简单** —— 密集、紧凑的网格
   - **中等** —— 均衡网格
   - **困难** —— 开阔、稀疏的网格
6. 点击**生成填字游戏**。

提示：**载入示例**填入 12 个水果词的示例；**清空**清空输入框。词表会自动存为草稿，误刷新也不丢。

## 用文章生成拼图

![文章模式候选词](../img/article-candidates-en.webp)

1. 切到**文章**标签。
2. 粘贴一篇英文文章（新闻、随笔或章节）。实时统计显示词数与句数；太短的文本会被拒绝。
3. 点击**提取候选词**。分析完全在浏览器本地完成：过滤功能词、复数归并（`ships`/`ship` 合并计数）、识别专有名词，其余按词频与位置评分排序。每个候选词显示出现次数（×3 等）。
4. 勾选想要的词，或用 **Top 10 / 全选 / 全不选**；还可在**添加单词**框手动补词（最长 12 字母）。
5. 选择**线索风格**：
   - **自动** —— 配置了 AI 用 AI 文章式，否则挖空
   - **选自原文（离线挖空）** —— 把单词从它自己的句子里挖掉：`选自原文："…the keeper trimmed the ______ each dusk"`
   - **AI 文章式** —— 引用你文章中的情节与措辞、模仿其语气的线索
6. 填标题/选难度，点击**生成填字游戏**。

一个候选词都没选时无法生成；至少选一个。

## 作答拼图

![作答界面](../img/solve-en.webp)

- **输入**：点击格子后键入。手机上弹出输入法也能用（一个隐藏输入框负责捕获）。
- **移动**：方向键移动；**空格**翻转横向/纵向；**Tab** 跳到下一条线索。
- **定位**：点击线索跳到对应单词；当前词与当前格持续高亮。
- **检查**：用红笔叉标出错误字母。
- **提示**：揭示当前词中一个正确字母。
- **揭示 ▾**：揭示当前字母、当前单词或整盘（揭示整盘需确认）。
- **重置**：清空这套题的所有作答（需确认）。
- **计时器**：作答时走表；完成时出现完成横幅。

进度按拼图自动保存：字母、揭示记录与用时在刷新后都在。进度以「布局+答案」为键，编辑线索或标题不会清空进度，重新生成则会。

## 编辑拼图

点击工具栏的**编辑**打开抽屉：

- 改**标题**。
- 改**难度**（重新生成时生效）。
- 改写**任意线索**。
- **保存修改**就地生效；**保存并重新生成**还会重排布局（你改过的线索会尽量套用到新布局）。

## 打印 / PDF

![打印预览](../img/print-preview-en.webp)

1. 点击**打印 / PDF**。弹窗里就是将要打印的真实 A4 页面。
2. 可覆盖**打印标题**（不影响拼图标题）、切换**显示日期**（或输入自定义日期）、勾选**添加答案页**（第二张纸，带填好的网格）。
3. 按**打印**选择打印机——或在浏览器对话框里选**存储为 PDF** 导出 PDF。输出为纯黑白。

## 分享拼图

点击**分享**：

- 有系统分享面板的手机上，会直接调起系统分享。
- 否则弹窗显示拼图链接（`…/#p=…`）供复制。

链接里就是整套拼图。任何人打开即得同一套题——无需服务器、无需账号。格式原理与防篡改校验见[分享链接](./features/share-links.md)。

## AI 线索 {#ai-线索}

Crossword Studio 可以通过任意 OpenAI 兼容的 `/chat/completions` 接口撰写线索：

| 服务商 | Base URL |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| 火山方舟 | `https://ark.cn-beijing.volces.com/api/v3` |
| DeepSeek | `https://api.deepseek.com/v1` |
| Ollama（本地） | `http://localhost:11434/v1` |

配置：点击右上角 **AI 设置** → 填 Base URL、API 密钥、模型名 → 保存。密钥只存你浏览器的 localStorage，只发给这个接口。

行为：

- 词表模式只补写空线索的条目。
- 文章模式发送文章节选（上限 12,000 字符）+ 选定词，每批 20 词，带进度显示；某一批失败不影响其他批。
- 线索风格随难度（简单=平实友好，困难=误导与双关）。
- 没配置 AI？一切照常——线索留空可编辑，文章模式回落到离线挖空。

网络细节：[隐私说明](./privacy.md)。设计决策：[AI 线索撰写](./features/ai-clues.md)。

## 错误处理

| 情况 | 行为 |
| --- | --- |
| 单词短于 3 个或长于 12 个字母 | 输入框下方列出（"最少 3 个" / 长度问题）；该词被忽略 |
| 含非 A–Z 字符（重音、连字符） | 先剥离再校验，剩余字母参与生成 |
| 重复单词 | 列为重复；只保留第一次出现 |
| 单词内含空格 | 列为空格问题 |
| 文章太短 | 「提取候选词」无可见反应——请粘贴更长的文本 |
| 没有单词 / 没选候选词就点生成 | 留在构建页；什么都不生成 |
| 选了 AI 风格但未配置 AI | Toast 提示未配置；留在构建页 |
| AI 接口不可达或被 CORS 拦截 | Toast 显示失败原因；其他功能照常 |
| 单词放不进棋盘 | 列在棋盘下方并给出原因：无公共字母 / 所有交叉冲突 / 超出难度网格上限 |
| 分享链接损坏或被改动 | 拒绝渲染并提示拼图数据无效 |

## 边界行为

- 重新生成会保留你改过的线索，但产生新布局（新种子）并清空进度。
- 打印专用标题覆盖从不改动拼图本身保存的标题。
- 切换语言会重建所有动态视图，但保留进度与运行中的计时器。
- 作答进度只属于当前浏览器配置；没有同步，也没有服务器副本。
